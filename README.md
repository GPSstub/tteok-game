## 로컬 실행

index.html을 브라우저에서 엽니다. 또는 이 폴더에서 python3 -m http.server 8000을 실행하고 http://localhost:8000을 엽니다.

## 파일

- index.html: 토끼
- pig.html: 돼지
- game.js: 공통 게임 규칙과 입력 처리
- style.css: 화면과 버튼 배치
- assets/: 긴빠이해옴
