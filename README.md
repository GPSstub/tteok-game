# 떡치기 연습 게임

토끼와 돼지 혼자 연습하는 웹게임입니다. 패턴마다 10초, 절구 6개, 최대 8줄 패턴을 지원합니다. 돼지 패턴은 다른 색과 보라가 한 세트로 나옵니다.

## 게임 규칙

- 패턴마다 10초, 절구는 6개입니다.
- 시간 초과 또는 오답 한 번마다 절구가 1개씩 줄고, 모두 잃으면 게임이 끝납니다.
- 송편을 많이 만들수록 높은 점수입니다. 점수가 같으면 최고 콤보가 높은 쪽이 앞섭니다.

## 랭킹

- 게임이 끝났을 때 TOP 10에 들면 이름(최대 8자)을 남길 수 있습니다.
- 토끼와 돼지 랭킹은 따로 저장됩니다.

## 로컬 실행

index.html을 브라우저에서 엽니다. 또는 이 폴더에서 python3 -m http.server 8000을 실행하고 http://localhost:8000을 엽니다.
